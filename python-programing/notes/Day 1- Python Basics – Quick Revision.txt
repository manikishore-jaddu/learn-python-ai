✅ 1. Printing Output
Used print() to show text and variables.


print("Hello, world!")
✅ 2. Variables & Literals
site1 = "python"
➤ site1 is a variable, "python" is a literal

Reassigning:


name = "python"
name = "python life"
Assign multiple values:


a, b, c = 1, 1.1, "python"
Assign one value to multiple variables:


site1 = site2 = "python"
✅ 3. Variable Naming Rules
Can contain: a–z, A–Z, 0–9, and _

Use meaningful names like vowel instead of v

Use _ for multiple words: my_name, current_salary

Case-sensitive: num ≠ Num

Avoid Python keywords like if, True, class

✅ 4. Numeric Literals
Integer – whole numbers (positive or negative): 5, -3

Floating-point – with decimal: 2.5, -1.0

Complex – with real + imaginary part: 6 + 9j or complex(x, y)

✅ 5. String Literals
Can use either 'single' or "double" quotes:


name = "Mani"
title = 'Python Dev'
✅ 6. Boolean Literals

is_pass = True
is_fail = False
✅ 7. Character Literal
A single Unicode character:


letter = 'K'
✅ 8. Special Literal

value = None
Means “no value” assigned.

✅ 9. Collection Literals
You learned 4 types:

Type	Example
List	fruits = ['mango', 'grapes']
Tuple	numbers = (1, 2, 3)
Dictionary	alphabets = {'a':'apple'}
Set	vowels = {'a', 'e', 'i'}
