Topic: String Manipulation

1. Reverse a String
Task: Take a string as input and print it reversed.

Hint: You can use string slicing: s[::-1]

2. Palindrome Checker
Task: Input a word, check and print if it is a palindrome (reads the same forwards/backwards).

Hint: Compare the string to its reverse.

3. Count Vowels in a String
Task: Input a sentence, count, and print the number of vowels (a, e, i, o, u).

Hint: Use a loop or a list comprehension.

4. Capitalize Each Word
Task: Input a sentence, print it with every word’s first letter capitalized.

Hint: Try title() method or split, capitalize, join.

5. Remove Duplicate Characters
Task: Given a string, return a new string with all duplicate characters removed, keeping only the first occurrences.

Hint: Loop through characters, add if not already in result.
