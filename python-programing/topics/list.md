## 21/07/25 Python Lesson Plan

Based on your structured daily practice, the next lesson should build on your recent focus: **strings**. To maintain clear progress, here’s a suggested set of topics and activities for your upcoming session.

### Topic: Python Lists

**Why lists?**  
Lists are the next fundamental data type after strings in Python. They allow you to store, access, and manipulate collections of data, which is essential for almost all real-world programming tasks.

#### What to Cover

- **What is a list?**
- How to create and print lists
- Accessing list elements using indices
- Slicing lists (similar to string slicing)
- Common list methods (`append`, `insert`, `remove`, `pop`, `index`, `count`, `sort`, `reverse`)
- Iterating through a list with a loop

#### Practice Problems for Tomorrow

1. **Create a List:**  
   Input several numbers or words and store them in a list. Print the list.

2. **Access and Slice:**  
   Print the first, last, and a slice (e.g., the middle three elements) from your list.

3. **Add and Remove Elements:**  
   Practice adding new values to the list (using `append` and `insert`) and removing items (`remove` and `pop`).

4. **Count and Sort:**  
   Count how many times a specific value appears in your list. Then, sort and reverse the list and print the results.

5. **Loop Through and Sum:**  
   Loop through the list, print each element, and calculate the sum (if your list contains numbers).

#### How to Study

- **Review basic list operations and syntax** in any beginner Python tutorial (such as W3Schools or GeeksforGeeks).
- **Experiment**: Change list content, method usage, and try with both numbers and strings.
- **Write comments** to explain each section of your code.
- **Push your work to GitLab** with a commit message like:  
  `2025-07-21: Practiced Python lists – creation, access, methods, and loops`

#### If You Finish Early

- Try nested lists (a list inside another list).
- Practice list comprehensions for simple transformations (e.g., square every number in a list).
